# Emoji Predictor Frontend Application

This folder contains the interactive React + TypeScript frontend for the Emoji Predictor application, built using Vite and TailwindCSS.

## Features
- Fully responsive modern glassmorphism UI.
- Real-time sentiment prediction using our NLP model hosted on Hugging Face Spaces.
- Fast Arabic-to-English translation fallback for native text inputs.
- Curated list of quick suggestion phrases.

## How to Run Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Instructions

1. **Navigate to the frontend directory:**
   ```bash
   cd web_ai-emoji-predictor
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Open [http://localhost:3000](http://localhost:3000) (or the port shown in your terminal) to view the application.
